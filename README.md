Страница обладает колоссальной, живой фан-базой и генерирует огромный объем активностей (лайки, просмотры, комментарии, репосты). Чтобы не терять время на полупустых пабликах, я взял этот датасет (выборка: 300 публикаций) для проведения глубокого, всестороннего исследования факторов вовлеченности (ER view).

## 🛠️ Пошаговый лог выполненных работ

В ходе работы над проектом мной было реализовано следующее:

### Шаг 1. Парсинг и сбор данных
* Осуществлен сбор «сырых» данных со стены официального сообщества Сергея Жукова с помощью API ВКонтакте.
* Извлечены текстовые составляющие постов, временные метки (`date`) и базовые метрики вовлечения (`likes`, `comments`, `reposts`, `views`).

### Шаг 2. Feature Engineering текста в Jupyter Notebook
* Написан алгоритм предварительной очистки от пунктуации и точный расчет использования верхнего регистра (`up_text`) — маркер постов, где более 10% слов написаны капслоком.
* Разработан бинарный признак присутствия эмодзи (`emoji`) на основе прямого сопоставления со словарями `emoji.EMOJI_DATA`.
* Создана метрика `er_view` (отношение суммы реакций к просмотрам) и проведено логарифмическое преобразование (`log1p`) всех таргетов для приведения к нормальному распределению.

### Шаг 3. Семантический анализ и NLP (pymorphy3 / NLTK)
* Проведена токенизация, вычищен текстовый мусор (местоимения, предлоги, союзы) с помощью библиотек `nltk`.
* Проведена глубокая лемматизация (приведение слов к начальной форме). 
* На основе частотного анализа лемм-лидеров (*концерт*, *ждать*, *бар*) массив постов оцифрован по 4 бизнес-категориям контента: Музыка/Бренд (`cat_nostalgia_brand`), Личный контент (`cat_personal`), Концертная деятельность (`cat_concert`) и Посты про бар (`cat_bar`).

### Шаг 4. Исследовательский и Корреляционный анализ
* Построена прямоугольная матрица линейной корреляции Пирсона между всеми текстовыми/временными фичами и логарифмированными метриками активности. 
* Обнаружен разрыв эффекта капслока (рост просмотров при падении ER) и сильный изолированный негативный тренд у коммерческих публикаций.

### Шаг 5. Статистическая проверка гипотез (SciPy)
* Проведена проверка подвыборок на нормальность с помощью критерия Шапиро-Уилка. Из-за зафиксированных отклонений (\(p < 0.05\)) параметрический t-тест был отклонен.
* Реализовано строгое тестирование через непараметрический **U-критерий Манна-Уитни**. Математически доказано влияние времени суток на вовлеченность (\(p = 0.000295\)) и зафиксирован чистый разрыв медианного ER между днем (1.76%) и ночью (2.60%).

### Шаг 6. Causal Inference (Причинно-следственный анализ)
* Построена множественная линейная регрессия OLS (`LinearRegression` из `sklearn`) для контроля смешивающих факторов (Confounding control). 
* Математически доказано, что негативный тренд постов о барах $\beta = -0.242$ и позитивный тренд выходных дней $\beta = +0.133$ являются изолированными эффектами, а не случайным совпадением контекстов.

### Шаг 7. Нелинейный анализ важности признаков (CatBoost)
* Обучена модель градиентного бустинга `CatBoostRegressor` на деревьях решений для поиска сложных нелинейных взаимосвязей.
* Построен график **Feature Importance**, показавший доминирующую важность длины текста `word_count` (33.9% вклада в модель) и темы продвижения заведений `cat_bar` (13.8%).

### Шаг 8. Бизнес-аналитика и Дашборд в Power BI
* Разработан executive-дашборд в премиальном темном концертном стиле. 
* Сетка выровнена по пикселям, метрики разделены во избежание искажения масштабов. Настроена интерактивная кольцевая диаграмма долей, рейтинг месяцев и распределение вовлеченности по времени суток. Добавлены выпадающие фильтры по типам контента и удобный календарный ползунок.

## 📈 Ключевые аналитические выводы:
1. **Прайм-тайм**: Аудитория артиста демонстрирует выраженное эмоциональное потребление контента. Ночные (2.69%) и вечерние (2.44%) посты работают на **47.5% эффективнее** дневных и утренних.
2. **Сезонный пик**: Март и Август — абсолютные лидеры по качеству отклика.
3. **Крах прямой рекламы**: Упоминание «баров» и перенасыщение текста эмодзи/капслоком значимо ухудшают метрики. Лояльное ядро фанатов отвергает агрессивный маркетинг, отдавая безусловный приоритет личным, неформальным публикациям артиста.
